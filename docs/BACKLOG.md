### 현재 시스템에서 제외한 검증

제외된 검증은 이번 환경에서 실행하지 않았다. 해당 공식 WBS·출시 판정은 기존 근거 범위에서 유지한다. 구현 또는 운영 기준이 남은 항목은 위 표에서 추적한다. [현재 실측과 재실행 범위](HANDOFF.md#현재-시스템에서-8단계-재검증)

| 작업 | 제외한 검증과 환경 제약 |
|---|---|
| DSG-07 · WBS 5.1 | macOS의 독립 운영 계정과 시스템 도메인 LaunchDaemon은 승인된 제한 계정·관리자 실행 경로가 확인되지 않았다. 사용자 GUI 도메인과 동일 UID 샌드박스는 재실행했다. Windows ARM64의 실제 Docker 연동은 검증된 로컬 엔진과 제한 SID 조합이 없다. 기존 SCM의 합성 상류 근거만 적용한다. |
| DSG-08 · WBS 6.1 | x64 운영체제에서 Windows 설치·업그레이드·제거를 수행할 네이티브 시험 환경이 확인되지 않았다. ARM64 게스트에서의 x64 에뮬레이션과 설치기 대상 거절 근거를 적용한다. |
