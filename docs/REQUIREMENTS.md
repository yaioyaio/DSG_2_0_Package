## 수용 기준

- REQ-007: Dry-run은 파일을 삭제하지 않는다.
- REQ-008: 변경된 경로/mtime/inode 감지 시 삭제 거절한다. 활동 중 프로세스 추적까지 완료되기 전 실사용 자동 삭제 금지.
- REQ-005: 태그만 동일하다는 이유로 재사용해서는 안 된다.
- REQ-010: 악의적 중첩 셸/직접 Docker API 우회는 Hook만으로 방지할 수 없음을 사용자에게 명시한다.
