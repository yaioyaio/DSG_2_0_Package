2026-11-24 기준. 공식 계획의 Phase 1~6과 실행 계획 초안의 0~7단계는 번호 체계가 다르다. 실행 계획의 0~7단계는 작업 DSG-01~08에 순서대로 대응한다. 공식 WBS 14개 항목 각각에 관련 DSG 작업, 계획 산출물·수용 기준, 구현 산출물과 시험 근거를 연결한다. [공식 계획](PLAN.md) · [WBS 원문](WBS.md) · [실행 계획과 통과 기준](draft/IMPLEMENTATION-PLAN.md) · [작업별 백로그](BACKLOG.md)

## 수용 기준 확정이 남은 항목

- 현재 운영 기준은 Docker 강제 통제를 OS 권한 경계에서 확인한다. 세 CLI 모두 훅 실패 시 차단해야 하는 경우에는 수용 기준과 검증 대상을 먼저 확정한다. [에이전트 운영 기준](OPERATIONS.md#에이전트-연동-운영)
- 실행 계획 7단계의 승인형 MCP와 서명·격리를 지원하는 Provider SDK(REQ-013)는 사용 사례 확정 후 개발한다. 3.1의 내장 Provider 시험은 등록된 정형 작업을 검증했다. SDK 검증은 별도 확장 과제로 추적한다. [요구사항](REQUIREMENTS.md) · [실행 계획](draft/IMPLEMENTATION-PLAN.md#단계별-산출물과-통과-기준)
